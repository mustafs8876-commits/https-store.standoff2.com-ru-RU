# Arena Break — готово для GitHub и Vercel

Порядок разделов: приветствие → видео «Как работает способ» → этапы действий → совместимость → дополнительные сведения → результаты → тарифы → получение доступа.

Загрузите `index.html` и `demo.mp4` в корень GitHub-репозитория. В Vercel выберите репозиторий, Framework Preset: Other, Build Command: пусто, Output Directory: пусто.

Кнопки покупки и получения доступа ведут на https://t.me/rolexgolda_shop. Кнопка «КАК РАБОТАЕТ?» прокручивает страницу к видео. Форма не отправляет данные — открывает Telegram.
